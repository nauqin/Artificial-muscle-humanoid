## 4. 개선 방법 후보

**근거** 열이 "결과 있음"이면 이번까지 실행한 숫자가 뒷받침하고, "아이디어"면 아직 해 보지 않은 것이다.

### 4-1. 배분비·토크 용량 단계

| 방법 | 내용 | 근거 | 비용 |
| --- | --- | --- | --- |
| 탐색 프레임 늘리기 | 600 → 2,000개 이상 | 결과 있음: 몸통 1,200회에서 탐색 표본 145, 약 3,000개 표본 158 N·m 로 벌어짐 | 낮음 |
| 동작별로 같은 수 뽑기 | 프레임 수가 많은 스쿼트에 쏠리지 않게 | 결과 있음: 하체 걷기만 재면 245.8 로 전체 237.4 보다 큼 | 낮음 |
| 시작값 늘리기 | 5개 → 20개 이상 | 결과 있음: 하체 시작값별 229~247 N·m | 낮음 |
| 경로까지 고려한 배분비 | 배분비 찾을 때 케이블로 만들기 어려운 값에 벌점, 또는 배분비와 부착점을 같이 최적화 | 결과 있음: 어깨 총 토크 용량 80.8·79.7·79.4 인데 걷기 87·33.5·0.1 % | 높음 |

평가 횟수 늘리기는 2.4~3.6 % 만 줄어서 후순위다.

### 4-2. 경로 단계

| 방법 | 내용 | 근거 | 비용 |
| --- | --- | --- | --- |
| 시드 여러 개로 돌려 편차 재기 | 같은 설계를 시드 5개로 | 결과 있음: 개수에 따라 결과가 들쭉날쭉. 11/2 후배 재현에서도 걷기 10.3 % 차이 | 중간 |
| 상한을 벌점 대신 확실한 제약으로 | 스트로크·힘 상한을 넘는 해를 버림 | 결과 있음: 1~4 mm 초과로 M1 로 올라간 케이블 4개 + 배정 불가 1개 | 중간 |
| 모듈 먼저 정하기 | 케이블별 등급 상한을 걸고 경로 설계 | 아이디어. 윈도우 세션용 프롬프트 준비됨 | 중간 |
| 힘 상한을 처음부터 2,700 N 으로 | 지금은 1,800 N 으로 경로를 찾은 뒤 힘만 ×1.5 해서 앞뒤가 다름 | 아이디어 | 낮음 |
| 사람 근육 부착점을 시작값으로 | MoBL 경로를 어깨 경로의 시작값·상자로 | 결과 있음: 사람은 팔 −22° 에서 앞삼각근 +4.1, 짧은 이두근 +3.5 cm 굴곡 모멘트암이 남음 | 중간 |
| 앞쪽 부착점 강제 | 어깨 케이블 하나를 가슴(몸통 x ≥ +5 cm)에서 출발 | 결과 있음: 6개 설계의 부착점이 전부 어깨 중심 근처 | 낮음 |
| 작은 케이블 정리 | 어깨 M0(0.9 N·m, 77 N)을 빼고 7개로 다시 확인 | 아이디어 | 낮음 |
| 뼈 간섭, 무릎·발목 감는 면 | 관절 중심 최소 거리, 감는 면 추가 | 결과 있음: 9월부터 남은 항목. 직선 케이블이 깊은 스쿼트에서 뼈를 가로지름 | 높음 |
| 건너는 관절 수 벌점 | 4바디 경로를 2~3바디로 | 아이디어. 하체 대부분이 4바디 경로라 제작이 어려움 | 중간 |

### 4-3. 검증 단계

| 방법 | 내용 | 근거 | 비용 |
| --- | --- | --- | --- |
| 시행 늘리기 | 걷기 1 + 들기 1 → 설계 입력 16시행 전부, 설계에 안 쓴 시행도 | 지금 어깨는 2시행만 봄 | 중간 |
| 피크도 같이 보기 | 95퍼센타일과 최대값을 함께 판정 | 결과 있음: 어깨 8개 걷기 95퍼센타일 0.1 % 인데 회전 피크 101 %(ID 피크 0.8 N·m 기준), 굴곡 피크 26.8 % | 낮음 |
| 왼팔·왼다리 따로 보기 | 대칭 복사 대신 왼쪽 지표도 판정 | 결과 있음: 어깨는 좌우 결과가 크게 달랐음 | 낮음 |
| 하중 바꿔 보기 | 물병 무게를 바꿔 어깨 여유 확인 | 아이디어 | 중간 |
| 동역학 검증 | SMA 응답 지연을 넣고 걷기·들기 | 아이디어. 지금 설계는 프레임을 따로 풀어 시간을 안 본다. MuJoCo 과제와 연결 | 높음 |
