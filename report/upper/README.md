# 상체(몸통 3자유도 + 오른팔 4자유도) 인공근육 설계 — 입력·가정·결과 (2026-11-03)

하체 설계(근육 8개, `report/`)와 같은 파이프라인을 설계 공간만 바꿔(`report/design_space.py`) 돌렸다.
입력 정본은 이 폴더의 `tasks.csv` 다. 한 줄 = trial 하나 = (IK, ID, 질량, 키, 과제, 손 하중).

용어 (2026-11-05 정함): 케이블 하나가 각 관절에 토크를 나눠 거는 비율 V 를 **관절 배분비**(예전 "방향"), 그 비율로 낼 수 있는 최대 세기 c 를 **토크 용량**(N·m, 예전 "용량"), 공간에서 케이블이 지나가는 방향을 **케이블 방향**이라 부른다. "방향"이 두 뜻으로 쓰여 헷갈려서 바꿨다. 코드의 변수·파일 이름(`V`, `design_directions`, `dir_err`)은 그대로다.

## 2. 상체 토크를 지면반력 없이 구해도 되는 이유

팔·몸통 관절 토크는 그 관절 위쪽 분절의 운동과 손 하중만으로 정해진다. 지면반력은 다리와 골반 잔차에만
들어간다. Moore T048_seg26 에서 GRF 를 넣고/빼고 ID 를 돌리면 arm_flex 15.08 vs 15.08, lumbar 39.25 vs 39.25
N·m 로 소수점 둘째 자리까지 같았다(2026-11-02). 그래서 CARRT 처럼 힘판이 없는 데이터도 그대로 쓴다.
단, 상체 ID 는 좌표를 **6 Hz** 로 거른다(15 Hz 는 팔 토크에 99퍼센타일의 2~3배짜리 잡음 스파이크가 남았다).

## 3. CARRT 처리에서 둔 가정

- 마커 43개 → Rajagopal 마커셋 35개 이름 매핑(`tools/carrt_prepare.py` `MAP`). 어깨 마커(RSHO)가 삼각근 위라
  상완 길이는 팔꿈치–손목 비례로 잡았고, RDELT/LDELT 는 모델에서 torso 에 붙어 있어 humerus 로 옮겼다.
- 스케일은 축별 측정(골반 폭 ASIS–ASIS, 몸통 C7–PSIS 등)으로 했고, MarkerPlacer 가 파이썬에서 마커를 안 옮겨
  정적 IK 로 직접 놓았다(`place_markers`).
- IK 마커 RMS: 상자 1.8 cm, 나머지 3.0~3.5 cm (최대 9~13 cm). 계획 기준(RMS < 2 cm)보다 크다 — 팔 회전은
  마커 3개뿐이라 믿을 수 없고, 극단 자세(어깨 회전 −170°)는 IK 가 꼬인 프레임일 수 있다.
- 물체 질량(논문 표 3): 상자 0.52 kg **양손 반씩**, 찬 물병 3.79, 빈 물병 0.90, 찬장 0. 손 바디에 질량만 더했고
  관성·잡는 위치 오프셋은 없다. "Half Body" 폴더는 마커 20개뿐이라 안 썼다.
- 피험자 키는 Data.xlsx 에 없어 1.626 m 로 통일(세그먼트 치수에서 추정). 정규화는 질량×키 비율.

### 11-2. 사전 배정 (`report/module_first.py`)

케이블 i 가 해야 하는 일 W = s × 1.1 × c × Δθ (J). Δθ 는 자세 표본(path_design 설계 자세 + stroke_check 검사 자세)에서 v·q 가 움직이는 범위(rad),
s 는 경로 뒤 힘 배율(어깨 1.5). 모멘트암 ρ 가 일정하면 힘 = s·1.1·c/ρ, ΔL = ρ·Δθ 라 힘 × ΔL = W. 등급 g 를 n 묶음 쓰려면
ρ ∈ [s·1.1·c/(n·F_g), S_g/Δθ] 이고, 이 구간이 있으려면 n ≥ W/(F_g·S_g). 등급마다 n 을 구해 **stroke_check 와 같은 규칙**(묶음 수 최소,
같으면 힘 상한이 작은 등급)으로 고른다. 결과(모든 케이블 1 묶음):

### 11-3. 새 방식 경로 설계에서 정한 것

- 케이블 i 에 등급 상한을 1 % 안쪽에 건다: 힘 ≤ 0.99 × 묶음 수 × 힘 상한 ÷ s, ΔL ≤ 0.99 × 스트로크 상한. 벌점 가중치는 9절과 같다(힘 5, 스트로크 50) —
  두 방식의 차이가 "상한이 케이블마다 다르다"뿐이도록. 부위 전체 상한(`--f-module`, `--stroke-max`)은 끈다.
- ΔL 은 설계 자세에 stroke_check 검사 자세까지 합쳐 잰다 — 등급을 정하는 자세를 설계가 보게.
- **수선**: 2단계 뒤 상한을 15 % 이하로 넘은 케이블만 그 케이블의 부착점·힘 배율을 국소 탐색(Nelder–Mead, 시작 크기 2 mm)해 상한 안에 넣는다(json `repair`).
  15 % 넘게 넘는 케이블은 그 등급으로는 안 되는 것이라 손대지 않고 "사전 배정 실패"로 센다.
- **신뢰 구간 2단계**(`--refine-trust 0.01`): 기본 2단계 Powell 은 한 방향 탐색을 상자 끝에서 끝까지 하는데, 1단계 해가 상한 경계에 붙어 있으면
  시작점보다 나쁜 점을 돌려줘 2단계가 아무것도 못 했다(하체 2.49 vs 시작 2.29, 어깨 10.58 vs 8.70). 현재 점 ±1 cm(힘 배율 ±0.1) 안에서 돌리고 옮겨 가며 반복한다.
  이 옵션은 현재 방식도 좋게 만든다(어깨 2단계 최악 28.9 → 15.0 %) → 현재 방식에 같은 옵션을 켠 결과를 "민감도" 줄로 같이 싣는다.
- 옵션을 주지 않으면 결과가 9절과 같다: 몸통을 원래 코드(git HEAD)와 고친 코드로 같은 조건으로 돌려 부착점·힘·2단계 기록 차이 0.

### 11-6. 결론

1. **몸통은 새 방식이 낫다.** 재현율은 그대로(걷기·들기 0 %)이고 M1 이 없어졌다(M1 1 + M2 3 → M3 2 + M2 2). 모멘트암이 자세에 따라 거의 안 변해서
   예측이 맞았다(실제/예측 1.14~1.34).
2. **하체는 등급과 재현율을 맞바꾼다.** 새 방식은 배정 불가 2 → 0, M1 2 → 1, 사전 배정 8개를 모두 지켰지만 스쿼트 보조가 1.5 → 16.7 % 로 기준(10 %)을
   넘었다. M4 를 M6(1,500 N·80 mm)에 넣으려고 방향을 31° 틀었기 때문이다. 걷기는 1.3 % 로 그대로.
3. **팔꿈치는 바뀌지 않는다.** 예측(M2)은 처음부터 불가능했고 결과는 두 방식 모두 M1 × 2, 재현 0 %.
4. **어깨는 판단 보류.** 새 방식은 M1 4 → 1 이고 걷기가 0.3 % 로 좋아졌지만 들기 최악이 68.6 % 다. 짐을 든 오른팔은 현재 방식과 비슷하고(굴곡 9.4 vs 8.1 %,
   회전 18.5 vs 17.3 %), 68.6 % 는 왼팔 회전(ID 최대 0.2 N·m)에서 나왔다. 같은 최적화기를 쓴 현재 + 신뢰 구간(22.8 / 5.7 %)보다 들기가 나쁘다.
   어깨 걷기의 경로 문제(9절)는 이 실험과 별개다. 새 방식 걷기 0.3 % 가 그 문제를 푼 것인지는 이 실험으로 판단하지 않았다.
5. **사후 배정은 경계에서 불안정하다.** 같은 코드·입력을 맥과 윈도우에서 돌리면 하체 부착점이 최대 7.3 cm 다르고(M6 2,045 → 1,400 N), 수정 후 하체는
   M4 가 120.2 mm 로 0.2 mm 차이에 배정 불가가 된다. 새 방식은 등급이 설계 입력이라 계산 차이로 등급이 뒤집히지 않는다.
6. **예측(W)은 하한이다.** 등급 여유가 실제/예측 비보다 작은 케이블은 사전 배정을 못 지키거나, 지키려고 방향을 틀어 재현율을 잃는다. 다음에는 사전 배정에
   평균/최소 모멘트암을 미리 넣는 것이 맞다(예: 현재 방식 1단계 해의 비를 W 에 곱해 등급을 고르기) — 이번 실험에서는 돌리지 않았다.

### 12-2. 알게 된 것

1. **기본 2단계가 자주 멈춘다.** 신뢰 구간 없이 돌린 현재 방식 12번 중 어깨 3/3, 하체 1/3(시드 1, 잔차 17.7 % 로 남음), 팔꿈치 3/3 에서 Powell 이 시작점보다 나쁜
   점을 돌려줘 1단계 해로 되돌아갔다(팔꿈치는 1단계가 이미 0 % 라 영향 없음, 몸통은 3/3 정상). **맥 채택 어깨 설계(`_s80_f15`)도 2단계가 안 돈 것이다** — 윈도우에서
   같은 조건으로 다시 돌리면 등급·Moco 숫자까지 같다.
2. **어깨는 경로로 된다.** 신뢰 구간 2단계로 같은 감는 구(3.95 cm)·힘 ×1.5 에서 시드 6개 중 4개(1~4)가 1.2·1.6 m/s 걷기와 찬 물병·상자 들기를 모두 2.0 % 이하로 냈다.
   통과한 4개는 2단계 잔차 최악이 8.9~13.4 %, 떨어진 2개(시드 0·5)는 15.0·17.6 % — **시드를 여러 개 돌려 2단계 잔차가 가장 작은 설계를 고르면** Moco 없이도
   통과 설계를 고를 수 있다(이번엔 시드 4: 8.9 %, 걷기 0.6 / 0.1 %, 들기 0.1 / 0.0 %). 통과·탈락 설계의 케이블 힘은 비슷하다(M1 1,470~1,751 N, 등급은 여섯 개 모두
   M6 1~2 + M2 0~1 + M1 4) — 차이는 힘보다 부착점이고, 걷기가 통과 경계 근처에 있다. 9절의 하드웨어 지렛대 결론은 이 결과로 다시 판단해야 한다.
3. **사후 배정은 시드에 따라 등급이 흔들린다.** 하체 현재 방식: M1 2 / 4 / 1, 배정 불가 2 / 1 / 2, 추정 질량 753~1,543 g. 모듈 먼저 계열은 등급이 설계 입력이라 시드와 무관하다.
4. **보정한 모듈 먼저가 하체의 답이다.** 사전 배정 8개를 시드 3개 모두 지키고(배정 불가 0), 스쿼트 1.5 / 3.7 / 1.5 %, 걷기 1.4~1.9 %, LabValidation 걷기 2.2~2.8 % 로 통과.
   M1 은 2개(M0·M4: 하체에서 ΔL 이 120 mm 가까이 필요한 케이블). 보정 없는 모듈 먼저(M1 1, 847 g)는 스쿼트가 세 시드 모두 미달(12.2~18.9 %).
5. **몸통은 보정 없는 모듈 먼저가 가장 가볍다**(220 g, M3 2 + M2 2, 세 시드 모두 0 %). 보정하면 M3 → M2 로 올라가 320 g — 몸통은 예측이 맞아서 보정이 오히려 손해.
6. **팔꿈치는 어느 방식이든 M1 × 2(667 g)**, 모든 동작 0 %. 보정하면 사전 배정이 M1 이라 "못 지킴"이 없어진다.
7. **어깨 모듈 먼저(M1 1, 733 g)는 걷기는 되지만 들기는 세 시드 모두 미달**(오른팔 18~24 %). 보정한 모듈 먼저(M1 3)는 시드 0·2 에서 들기는 되지만 걷기가 21~23 % 로 미달.
