# SMA 근육 모델 — 기계연 실제 값 (11/20, 김은서)

## 파일
| 파일 | 내용 |
|---|---|
| `sma_model.py` | SMA 근육 모델 v3 (잠열, 온도 튐 수정, 기계연 실제 값만) |
| `kimm_arm.py` | 기계연 팔 — **예전 설정** (평균 오차 15.9°) |
| `kimm_arm_new.py` | 기계연 팔 — **새 설정** (교수님 방식 근육 달기 + 팔 팬 냉각 0.6 배, 평균 오차 4.7°) |

필요: `pip install mujoco numpy` · 돌리기: `python kimm_arm.py` / `python kimm_arm_new.py` (각 1~2분)

## 두 팔 설정 비교
| | 예전 설정 `kimm_arm.py` | 새 설정 `kimm_arm_new.py` |
|---|---|---|
| 근육 다는 방식 | 이두는 0°, 삼두는 82.5° 에서 최대 길이 (삼두 느슨) → 다 식은 삼두는 늘어나도 저항 0 | 0° 에서 두 근육 모두 최대 길이 (교수님 `elbow_rig.py` 와 같음) → 굽히면 삼두가 최대 길이를 넘어 다 식어도 버팀 |
| 팔 실험 팬 냉각 | 근육 하나 시험 냉각 그대로 (4.62 W/K) | 그 0.6 배 (2.77 W/K) |
| 굽힘 0.125 / 0.25 / 0.5 / 1 Hz | 77.9 / 73.2 / 32.8 / 1.4° | 57.7 / 48.2 / 27.9 / 9.7° |
| 실측 | 59.8 / 50.4 / 35.6 / 14.1° | 59.8 / 50.4 / 35.6 / 14.1° |
| 평균 오차 | 15.9° | 4.7° |

- 새 설정의 두 가지는 **가설** (기계연 확인 안 됨) → "재현" 이라고 하지 않음
- 팬 냉각 0.6 배는 굽힘 크기를 보고 고르지 않고, 0.125 · 0.25 Hz 에서 이두를 끈 뒤 팔이 내려오는 모양으로 정함 (두 빠르기가 따로 같은 값)
- 1 Hz 에서 처음 몇 회 굽힘이 점점 커지는 모양, 매 회 거의 0° 로 돌아오는 모양도 새 설정이 실측과 비슷함
- 0.5 · 1 Hz 는 새 설정도 아직 조금 덜 굽음 → 빠른 쪽 원인 일부 남음
- 자세한 정리 · 확인해 본 다른 가설 (열 ×2·×4, 감쇠, 삼두만 일찍 팽팽) 은 노션 "기계연 팔 실험 차이 원인 찾기" 참고
- 기계연 원본 데이터는 공개 레포라 올리지 않음

## 쓰는 법 (근육 모델)
`sma_model.py` 에는 기계연 실제 값만 들어 있음 (v3: 예전 값 · 스프링 힘 식 뺌).
```python
import sma_model as sm
mus = sm.SMA()                                   # 기계연 실제 값 (길이 0.18 m, 최대 수축 0.40, 힘 식 T3.1)
P = sm.heat_from_current(전류)                    # 열 [W] = 267 × (전류 / 36)²
F = mus.step(P if 켜짐 else 0.0, dt, eps=변형률, hS=냉각세기)   # 힘 [N]
# 냉각세기 [W/K]: 강제 4.62 · 반냉각 2.31 · 켜는 동안 0.72 [가정]  (sm.KIMM_HEAT 에 있음). 팔 실험 새 설정은 강제 · 반냉각 × 0.6
```

### 예전 코드에서 바뀌는 것 (v2 → v3)
| | 예전 (v2 `SMA()` 기본) | 지금 (v3) |
|---|---|---|
| 근육 길이 · 최대 수축 | 0.15 m · 0.40 | 0.18 m · 0.40 |
| 힘 식 | 스프링 (Park) | 교수님 T3.1 (스프링 식은 뺌) |
| 기본 냉각 `hS` | 3.6 W/K | 4.62 W/K (강제 냉각) |
| `power_duty(1)` | 977 W | 267 W (= 36 A) |
- `SMA(sm.M3_KIMM)` 로 쓰던 코드는 그대로 돌아감 (`M3_KIMM` = `M3`, 결과 같음)
- `power_duty(u)` 로 듀티를 주던 제어기 (예: 물병 들기, 상한 0.32 × 977 = 313 W) 는 같은 u 에서 열이 약 1/3.7 로 줄어듦 → 상한 · 제어 세기 다시 맞춰야 함
- `force_model="spring"` 옵션은 없어짐

## 실제 값 (기계연 회신 · 원본 데이터)
| 항목 | 값 | 출처 |
|---|---|---|
| 근육 길이 · 최대 수축 | 0.18 m · 0.40 | 회신 + 하중 곡선 |
| 가열 · 강제 냉각 | 267 W (36 A) · 4.62 W/K | 근육 하나 실험 (5 kg, 0.5 Hz, 36 A) 에 맞춤 |
| 팔 실험 전류 | 25 / 29 / 29 / 29.5 A (0.125 / 0.25 / 0.5 / 1 Hz) | 회신 |
| 모멘트 팔 (팔꿈치 ~ 와이어 부착점) | 50 mm | 회신 |
| 하중 | 0.5 kg, 팔꿈치에서 320 mm | 회신 |
| 냉각 방식 | 블레이드: 데우기 1/4 → 반냉각 1/4 → 강제 1/2, 반냉각 때 두 근육 모두 절반 | 회신 |

※ 팔 실험 굽힘은 값 맞추는 데 안 씀 (확인용).
