# SMA 근육 모델 — 새 모델 (11/22, 김은서)

> 위 폴더 (`sma_arm_kimm/`) 의 kimm_arm.py · kimm_arm_new.py 는 11/20 전 모델. 이 폴더는 11/22 새 모델 (세 파일이 한 폴더에 같이 있어야 돌아감)

## 파일
| 파일 | 내용 |
|---|---|
| `sma_model.py` | SMA 근육 모델 (잠열, 온도 튐 수정, 기계연 실제 값) |
| `arm.py` | 기계연 1자유도 팔 + 이두 · 삼두. 그대로 돌리면 **전 모델** |
| `new_model.py` | `arm.py` · `sma_model.py` 위에 **새 모델 값만 바꿔 끼운 것** |

필요: `pip install mujoco numpy`
- 전 모델: `python arm.py --mode prof --cx 0.6` (교수님 방식 근육 달기 + 팔 팬 냉각 ×0.6, 1~2분)
- 새 모델: `python new_model.py` (팔 네 빠르기 · 무게별 · 근육 하나 요약, 2코어 약 5분)

## 전 모델 → 새 모델
| | 전 모델 | 새 모델 |
|---|---|---|
| 근육 최대 힘 | 450 N (규격표 목표) → 팔에서 최대 308 N | 89.3 N **[가정]** (5 · 6 kg 추세를 늘린 짐작) |
| 무거우면 덜 줄어듦 | 없음 (40 % 고정) | 5 kg 39.0 % · 6 kg 29.5 % 를 지나는 선 |
| 최대 수축 | 0.40 | 0.42 (3 · 4 kg 하한 41 % 이상과 안 어긋나는 가장 작은 값) |
| 변태 온도 구간 | 55→72 °C | 2.5배 (42.25→84.75 °C, 유효 구간) |
| 가열 · 강제 냉각 (근육 하나 11쪽에 맞춤) | 267 W · 4.62 W/K | 344.5 W · 3.005 W/K |
| 근육 다는 각도 · 팔 냉각 | 교수님 방식 · ×0.6 | 삼두 40° · ×1.4 (한 빠르기씩 빼고 골라도 40°) |

- 근육 하나 (11쪽): 1회 36.7 · 4회 45.7 · 25회 45.8 mm (실측 39.4 · 47.3 · 44.3), 끈 뒤 절반 풀림 0.38 s (실측 0.38)

## 한계
- 변태 구간 폭, 가열 · 냉각, 근육 힘 (5 · 6 kg), 팔 냉각, 근육 다는 각도는 **맞춘 값**이라 "맞춘 모델" 이지 검증된 모델은 아님
- 근육 최대 힘 89 N 은 가정값. 60 / 90 / 130 / 150 N 으로 바꾸면 팔 예측 오차가 6.2 / 2.1 / 2.7 / 3.8° 로 달라지고, 어느 자료로도 하나로 정해지지 않음
- 1 Hz 는 실측보다 조금 더 굽음 (원인 모름)
- 자세한 과정은 노션 "SMA 근육 모델 — 새 모델 (11/22)" 참고
- 기계연 원본 데이터는 공개 레포라 올리지 않음
